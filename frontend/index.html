Project overview

CoolRun AI combines official Vienna aerial orthophotos, Roboflow tree detection, thermal-comfort analysis, and walking route alternatives to recommend routes with more shade potential.

Input data

  • City of Vienna Orthofoto / ViennaGIS WMTS imagery
  • Roboflow tree detections exported as GeoJSON
  • Optional Infrared UTCI grids and summary outputs
  • OpenRouteService walking alternatives from the backend
